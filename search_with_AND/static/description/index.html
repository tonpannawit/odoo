Search with AND Logic

By default, Odoo uses OR logic when you select multiple search terms in a field. This module overrides that behavior globally to use AND logic.

  • Strict Filtering: Results must match ALL selected terms.
  • Universal Support: Works on Products, Sales, CRM, and Custom Models.
  • Clear UI: Updates search facets to visually display "and" instead of "or".

Every search filter should narrow down and decrease your search results, not increase them.

This module makes sure you get closer to the result(s) you are looking for in every search.

Example

Odoo's Default Logic: Search "Blue" + "Red" → Shows everything Blue OR Red.

**the more you search, the more results you see. it doesn't make sense at all!!

With This Module: Search "Blue" + "Red" → Shows only items that are BOTH Blue AND Red.

**the more you search, the less results you see, getting you closer to what you are looking for.
